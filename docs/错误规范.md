# 公共错误规范

[返回中文 README](../README.md)

组件通过 `io.github.jasper.monitoring.api.error` 提供框架无关的稳定错误契约。错误码用于机器判断；异常消息只用于安全诊断，宿主不得解析消息，也不得把异常 cause 暴露给外部客户端。

## 异常层级

所有公共异常都实现 `MonitoringFailure`。`MonitoringValidationException` 继承 `IllegalArgumentException`；`MonitoringConfigurationException` 与 `MonitoringStateException` 继承 `IllegalStateException`；`MonitoringPersistenceException` 继承 `RuntimeException`。这保留了旧调用方的捕获兼容性。

## 错误码

| 错误码 | 枚举名 | 异常类型 | 重试建议 | 宿主责任 |
| --- | --- | --- | --- | --- |
| `MON-001` | `REQUIRED_FIELD_MISSING` | Validation | 原输入不重试 | 补齐必填安全字段。 |
| `MON-002` | `INVALID_FIELD_VALUE` | Validation | 原输入不重试 | 修正格式、范围或参数路径。 |
| `MON-003` | `UNSAFE_EVENT_ATTRIBUTE` | Validation | 原输入不重试 | 删除敏感或不支持的属性。 |
| `MON-101` | `ACTION_NOT_REGISTERED` | Validation | 配置修复后重试 | 记录前注册静态动作定义。 |
| `MON-102` | `CONFLICTING_ACTION_DEFINITION` | Configuration | 不自动重试 | 保证同一动作的所有定义一致。 |
| `MON-103` | `RULE_REGISTRY_FROZEN` | State | 不自动重试 | 在监测器创建前注册规则。 |
| `MON-104` | `DUPLICATE_CONTROL_BINDING` | Configuration | 不自动重试 | 每个动作仅保留一个宿主绑定。 |
| `MON-105` | `INVALID_CONTROL_TRIGGER` | Validation | 修复代码后重试 | 修正公开性、参数、返回类型或动作。 |
| `MON-106` | `DUPLICATE_INTERNAL_RULE_ID` | Configuration | 不自动重试 | 每个规则 ID 仅保留一个实现。 |
| `MON-201` | `ALERT_NOT_FOUND` | Validation | 刷新标识后决定 | 重新读取告警并校验 ID。 |
| `MON-202` | `INVALID_ALERT_TRANSITION` | State | 刷新状态后决定 | 选择当前状态允许的迁移。 |
| `MON-301` | `ENFORCEMENT_HANDLER_REQUIRED` | Configuration | 不自动重试 | 启用 `ENFORCE` 前注册并验收真实处理器。 |
| `MON-401` | `PERSISTENCE_OPERATION_FAILED` | Persistence | 仅按幂等策略重试 | 检查迁移、连接、权限和数据库健康；内部日志保留 cause。 |

已分配错误码不会改名或复用；后续小版本可以新增错误码。错误码不是 HTTP 状态码、RPC 状态或消息确认语义，协议映射由宿主边界决定。

## 宿主接入

```java
try {
    monitor.record(draft);
} catch (RuntimeException exception) {
    if (!(exception instanceof MonitoringFailure)) {
        throw exception;
    }
    MonitoringErrorCode code = ((MonitoringFailure) exception).getErrorCode();
    // 宿主将 code 映射到自己的 HTTP、RPC 或消息响应契约。
    auditLogger.warn("monitoring_failure_code={}", code.getCode());
}
```

日志只记录稳定错误码和经批准的稳定标识。不得记录密码、令牌、Cookie、原始请求/响应体、SQL 文本或把数据库异常直接返回客户端。未知 `RuntimeException` 不会统一包装，以免掩盖编程缺陷。
