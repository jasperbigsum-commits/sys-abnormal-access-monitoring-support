## 明确延期

- 自动执行 Schema 迁移：数据库变更仍由宿主受控迁移系统负责。
- 自动发现事实提供器：事实必须通过显式 `FactBinding` 声明目标、范围和 `FactSource`，不得扫描任意宿主 Bean 后自动接入。
- 自动在线激活数据库规则：在加载器具备校验、审批、灰度和回滚之前，持久化规则仅是管理数据。
- 内置 HTTP 错误信封：组件保持协议无关，宿主依据[错误规范](错误规范.md)映射。

排期原则是先补足可观察、可恢复和可治理能力，再扩展自动化。相关边界见[架构与运维说明](架构与运维说明.md)。
