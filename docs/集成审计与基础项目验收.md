# 集成审计与基础项目验收

`integration-audit/spring2-web` 和 `spring3-web` 是独立可启动的宿主应用，分别验证 `javax.servlet`/Java 8 与 `jakarta.servlet`/Java 17。两者使用真实嵌入式 Web 容器、Starter 自动配置、MyBatis、H2、Shiro 测试身份和宿主控制 Bean。

H2、固定测试身份和成功控制器仅用于验收，不能作为生产认证、数据库或控制实现。

## 执行

```bash
mvn -pl integration-audit/spring2-web -am test
mvn -pl integration-audit/spring3-web -am test
```

Surefire 证据分别位于两个模块的 `target/surefire-reports/`。

## 覆盖范围

| 场景 | 证据 |
| --- | --- |
| 资源范围允许/拒绝 | HTTP 状态、业务调用次数、`authz:*` 强类型事件 |
| 登录失败窗口 | 连续请求、`AUTH-01` 告警、验证码和限流持久控制 |
| 报表导出 Fact | `ReportExport`、资源 ID、数量、`EXPT-01` 告警 |
| MVC 注解 | `@MonitorAction(BuiltInActions.Query.class)` 生成查询事件 |
| MyBatis-only | 测试注入 `MyBatisMonitoringStore`，直接查询 SQL 事实 |
| 管理服务 | 注入 `SecurityEventQueryService`，验证成功和跨系统拒绝 |
| 管理审计 | `management_audit` 同时存在 `SUCCEEDED` 与 `DENIED` |
| 控制覆盖 | ENFORCE 宿主声明内置规则所需全部控制类型 |
| Boot 对称 | 两个宿主执行同一验收语义 |

窗口验收发送足够事件跨越数据库时间精度差异；核心回归同时验证当前事件即使被数据库查询省略，也会以原始事件参与规则评估。

## 验收边界

集成项目证明组件契约、自动配置、HTTP 适配和 MyBatis 持久化能够协作，但不能替代：目标数据库并发/索引测试、生产身份系统、真实控制副作用、数据留存和灾备演练。宿主上线材料应把这些外部证据与本项目 Surefire 报告关联。
